# Talent Habitat — website

Static marketing site for Talent Habitat: exceptional South African talent, intelligent technology and modern operations for global companies.

- `index.html` — the site (single page, no build step)
- `img/` — photography (placeholders, credited in the footer) and client logos
- `favicon.svg` — the tH mark

Hosted on GitHub Pages from the `main` branch. Currently **staging**: the page carries a `noindex` tag until launch.
